# progetto-API
Prova Finale di Algoritmi e Strutture Dati (Data Structures and Algorithms final project). Polimi, a.a. 2023/2024. Final grade: 30/30

The Algorithms and Data Structures course final project consisted in implementing and optimizing a complex algorithm in C. The algorithm manages a bakery, handling orders, recipes, deliveries, ingredient stocks and expiration dates.
Evaluation was based on correctness and performance using a set of secret testcases.
